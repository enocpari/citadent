# 🦷 CitaDent

Sistema de agendamiento de citas para consultorios dentales con un agente de IA
que atiende a los pacientes por chat, 24/7.

> **Estado:** 🚧 En desarrollo (aprendiendo mientras construyo)

---

## 🎯 ¿Qué quiero lograr?

Que un paciente pueda escribir por chat:
> *"Hola, me duele una muela, ¿tienen algo mañana?"*

Y que un agente de IA:
1. Entienda el mensaje
2. Revise qué horarios están libres
3. Agende la cita
4. La muestre en un panel web para el dentista

Todo sin que el dentista tenga que contestar el teléfono.

---

## 🧠 ¿Por qué hago este proyecto?

Porque quiero aprender, haciendo algo real, estos temas:

- Cómo funciona una **API** (backend que responde a peticiones)
- Cómo se organiza un proyecto con **arquitectura por capas** (parecido a MVC)
- Cómo **conectar una IA** a datos reales (function calling)
- Cómo servir un **frontend simple** que hable con el backend

No soy experto. Estoy aprendiendo. Este README es mi mapa.
