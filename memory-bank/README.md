# Memory Bank — CitaDent

Archivos principales:

- `projectbrief.md` — resumen del proyecto.
- `productContext.md` — por qué existe y para quién.
- `activeContext.md` — foco actual, cambios recientes y próximos pasos.
- `systemPatterns.md` — arquitectura, patrones y rutas críticas.
- `techContext.md` — tecnologías, restricciones y entorno.
- `progress.md` — qué funciona, qué falta y evolución.

## Uso
Estos archivos guían la continuidad del proyecto entre sesiones.
Actualizarlos al finalizar cada unidad de trabajo relevante.
