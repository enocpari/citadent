# Resumen del proyecto — CitaDent

## Descripción
CitaDent es un sistema de gestión de citas para una clínica dental. Ayuda a pacientes y al personal a organizar turnos, dentistas, horarios y seguimientos.

## Estado actual
Está en desarrollo. Actualmente funciona como una aplicación CLI en Python con separación en modelos y servicios.

## Alcance
- Gestión de pacientes.
- Gestión de dentistas.
- Gestión de citas.
- Gestión de horarios de atención.
- Búsquedas y filtros básicos.

## Objetivo a largo plazo
Evolucionar hacia una experiencia web y automatizada, con IA y posible canal de WhatsApp.

## Restricciones actuales
- Almacenamiento en memoria.
- Sin base de datos persistente.
- Interfaz principal por consola.
