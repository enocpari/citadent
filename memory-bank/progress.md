# Progreso — CitaDent

## Qué funciona
- CRUD de pacientes, dentistas, citas y horarios.
- Búsquedas y filtros básicos.
- Validación de horarios.
- Menús CLI.
- Modelos con herencia y métodos abstractos.

## Qué falta
- Persistencia en base de datos.
- Tests automatizados.
- Frontend web.
- Integración con IA y WhatsApp.
- Recordatorios automáticos.
- Autenticación y roles.

## Problemas conocidos
- Pérdida de datos al reiniciar.
- No hay ORM ni repositorios.
- Algunas búsquedas dependen de atributos específicos.
- Falta validación más estricta.

## Evolución
- Proyecto iniciado como CLI de aprendizaje.
- Se separaron modelos y servicios.
- Se reorganizó el menú de administrador.
- Se separó la capa CLI en módulos independientes (`cli/`).
- Se mantiene documentación de referencia del sistema original.
